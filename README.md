# Bilder Schweizer Infrastukturen (BilderCHInfra)
BilderCHInfra project - creating (new) visualisations for complex infrastucture networks in an interdisciplinary research project between the institute of architecture and the institute of geomatics of the university of applied sciences northwestern switzerland. 

Following examples display different visualisation types developed during the research project based on different usecases:
